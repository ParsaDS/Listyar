# لیست‌یار (Listyar)

A native Android plumbing-supplies list app built with Kotlin and Jetpack Compose.

## Current starter
- Persian RTL interface
- Home screen and bottom navigation (Lists, Home, Settings)
- New-list entry point
- Light Compose Material 3 foundation

## Open in Android Studio
1. Download or clone this repository.
2. Open the repository folder in Android Studio.
3. Allow Gradle sync to finish.
4. Run the `app` configuration on an emulator or Android phone.

The app is an initial foundation; local database persistence, editable pipe/fitting catalog, and the separate project-information/items screens will be added in follow-up commits.
